# 系统架构设计师考试助手

## 功能概述

当用户提供考试题目时，本 skill 会：
1. 使用 scan_markdown.py 脚本扫描教材章节
2. 根据题目内容检索相关知识点
3. 提供准确答案和详细解析

## Running scripts

Before invoking any bundled script:

1. Identify the directory containing this `SKILL.md`; call it `SKILL_DIR`.
2. Run scripts using paths joined from `SKILL_DIR`, for example:
   `python <SKILL_DIR>/scripts/build_index.py`
3. Do not use `./scripts/...` unless the shell has first changed into `SKILL_DIR`.

## 工作流程

### 步骤 1：扫描教材章节

当用户提供考试题目时，首先运行扫描脚本：

```bash
python <SKILL_DIR>/scripts/scan_markdown.py ./教材/系统架构设计师教程/chapters -o /tmp/content.index -v
```

### 步骤 2：读取扫描结果

读取生成的索引文件：
```bash
cat /tmp/content.index
```

### 步骤 3：分析题目并检索知识点

1. **提取题目关键词**：从题目中提取关键概念、技术术语、架构模式等
2. **匹配扫描结果**：在索引文件中查找包含相关关键词的标题和加粗文本
3. **定位相关章节**：根据匹配结果确定相关的 markdown 文件和行号

### 步骤 4：精确查找知识点

如果找到相关文件，读取该文件并查找具体知识点：
1. 使用 Read 工具读取对应的 markdown 文件
2. 根据行号定位到具体内容
3. 查找与题目直接相关的知识点

### 步骤 5：提供答案和解析

根据检索结果提供答案：
- **如果找到相关知识点**：基于教材内容提供准确答案，并引用具体出处
- **如果未找到直接相关内容**：基于系统架构设计知识自行分析题目，提供专业解答

## 关键词匹配策略

### 题目分析要点
1. **技术术语识别**：识别题目中的架构模式、设计原则、技术概念
2. **问题类型判断**：判断是概念题、应用题还是分析题
3. **知识点分类**：确定题目所属的知识领域（架构风格、质量属性、设计模式等）

### 常见考点分类
- **架构风格**：分层架构、微服务、SOA、事件驱动等
- **质量属性**：性能、可用性、安全性、可修改性等
- **设计模式**：创建型、结构型、行为型模式
- **架构评估**：ATAM、SAAM等评估方法
- **系统设计**：数据库设计、接口设计、分布式系统等

## 特殊情况处理

### 1. 扫描失败处理
如果 scan_markdown.py 执行失败：
1. 检查文件路径是否正确
2. 确认 Python 环境可用
3. 手动读取 chapters 目录下的相关文件

### 2. 无相关知识点
如果扫描结果中没有直接相关的知识点：
1. 基于系统架构设计知识进行分析
2. 提供相关的理论背景和实际应用示例
3. 建议用户查阅其他参考资料

### 3. 多个相关章节
如果题目涉及多个章节的内容：
1. 综合多个相关知识点
2. 说明各知识点之间的关系
3. 提供完整的答案框架

## 注意事项

1. **准确性优先**：确保答案基于教材内容或可靠的知识体系
2. **引用出处**：尽可能引用教材的具体章节和内容
3. **清晰解析**：提供详细的解析过程，帮助用户理解
4. **扩展知识**：在必要时提供相关的扩展知识点

## 相关工具

- **scan_markdown.py**：扫描教材章节，提取标题和加粗文本
- **Read 工具**：读取具体的 markdown 文件内容

建议定期运行扫描脚本以更新索引文件：
```bash

```
