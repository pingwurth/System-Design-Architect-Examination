# 亿图脑图 AI 页面参考文档

## 目标页面

- **URL**: https://mm.edrawsoft.cn/app/aiagent
- **浏览器要求**: 仅支持 Chrome 浏览器
- **功能**: 上传文件 → AI 自动生成思维导图

## 页面结构

页面主要分为三个区域：

### 左侧边栏 — 对话历史
- "历史对话" 标题
- "新建对话" 按钮
- 最近的对话列表，每个条目显示对话摘要

### 中间主区域 — AI 对话区
- 顶部：欢迎语 "您好，我能为您做什么"
- 中间：对话消息流（用户上传文件/输入 → AI 回复生成结果）
- AI 回复中会包含：
  - "已根据上传的文件内容生成思维导图。" 提示
  - "思维导图" 快捷按钮（可跳转到导图编辑页）
  - "修改"、"复制" 按钮

### 底部 — 输入区域
- 文本输入框
- AI 模型选择（如 "DeepSeek-V4-Flash"）
- "联网搜索" 按钮
- 可能包含附件/文件上传按钮

## 关键交互元素

### 文件上传（关键实现细节）

亿图脑图使用 **Element UI 的 `el-upload` 组件**，其 `<input type="file" class="el-upload__input">` 默认 `display:none`，
不会出现在 `take_snapshot` 结果中，导致 `upload_file` 找不到元素。

**必须步骤**：每次上传前先执行 JS 将 input 变为可见：
```js
const fi = document.querySelector('input.el-upload__input');
fi.style.cssText = 'display:block !important; position:fixed !important; top:100px !important; left:100px !important; z-index:99999 !important;';
```

> **注意**：点击"新建对话"后 DOM 会重置，需要对每个文件重新执行此 JS。

亿图脑图 AI 也支持以下方式（备用）：
1. **聊天输入框附件按钮**：点击输入框旁的附件图标，选择文件
2. **拖拽上传**：将文件拖拽到聊天区域
3. **输入框粘贴**：在输入框中提及文件名或路径引导上传

### 新建对话按钮

- 位于左侧边栏
- 文本: "新建对话"
- 点击后重置对话上下文，回到初始欢迎状态

### 生成完成标志

以下任一出现即表示导图已生成：
- 页面出现文本: "思维导图已生成"
- 页面出现文本: "已根据上传的文件内容生成思维导图"
- 页面出现 button "思维导图"

**等待策略**：不要用 `wait_for`（它有 15 秒硬超时限制！），用 `take_snapshot` 每 8-10 秒轮询。
每次轮询时输出等待时长，让用户知道进度。

## 常见问题排查

### `wait_for` 总是提前超时
MCP 的 `wait_for` 工具有 **15 秒硬超时限制**，无论 timeout 参数设多大。
替换方案：使用 `take_snapshot` 手动轮询，检查快照中的文本是否出现。

### upload_file 报"找不到上传元素"
`el-upload__input` 默认隐藏，必须先执行 JS 暴露它才能被 snapshot 捕获到 uid。

### 点击"新建对话"后 input 再次消失
"新建对话"会刷新 DOM，隐藏 input 恢复默认。需要在每个文件循环中重新执行 JS 暴露步骤。

### 上传后无反应
- 检查文件大小是否超过限制
- 确认网络连接正常
- 尝试刷新页面后重试

### "新建对话"按钮不可点击
- 确认上一个对话的 AI 回复已完全生成（"停止生成"按钮消失）
- 等待 2-3 秒让页面渲染完成

### 页面加载缓慢
- 检查 Chrome 浏览器版本是否最新
- 禁用不必要的 Chrome 扩展
