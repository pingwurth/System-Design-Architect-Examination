# 系统架构设计师考试笔记生成器

## 概述

本技能专注于为《系统架构设计师考试》生成高质量的结构化学习笔记。基于《系统架构设计师教程》，自动识别和提取关键知识点，按照考试要求组织内容，生成便于复习和记忆的笔记。

## 核心功能

### 1. 自动识别关键知识点类型

技能能够识别以下10类知识点：

| 类型 | 识别关键词 | 考试重要性 |
|------|------------|------------|
| 关键时间节点和里程碑事件 | 年份、"第一次"、"首次"、会议、标准发布 | ★★★★ |
| 重要概念和定义 | "是指"、"定义为"、专业术语、缩写 | ★★★★★ |
| 核心理论和方法 | "方法"、"技术"、"理论"、分析、设计 | ★★★★★ |
| 发展阶段划分 | "阶段"、"时期"、时间范围 | ★★★★ |
| 重要人物和机构 | 人名、机构名、"提出"、"研究" | ★★★ |
| 经典案例和数据 | 百分比、数字、"调查"、"统计" | ★★★★ |
| 设计原则和规范 | "原则"、"规则"、编号列表 | ★★★★ |
| 架构风格分类 | "风格"、"模式"、"分类" | ★★★★ |
| 对比分析 | "vs"、"区别"、"对比" | ★★★ |
| 生命周期影响 | "阶段"、"影响"、需求、设计、实现、维护 | ★★★ |

### 2. 结构化笔记生成

按照标准化模板生成笔记，包含：
- 表格形式的时间节点、人物贡献、概念对比
- 编号列表的概念定义、设计原则
- 分类整理的理论方法、架构风格
- 考试重点标注（选择题、案例分析题、论文写作题）

### 3. 考试重点标注

针对不同题型标注重点：
- **选择题重点**：时间节点、数字数据、概念定义、方法缩写、人物贡献
- **案例分析题重点**：方法应用、原则实践、问题解决
- **论文写作题重点**：理论框架、实践经验、发展趋势

## 工作流程

### 流程1：章节笔记生成

```
1. 读取指定章节内容
2. 识别知识点类型（使用关键词匹配）
3. 按照模板整理笔记
4. 生成结构化笔记文件到学习记录目录
```

### 流程2：特定主题笔记

```
1. 定位相关章节（使用索引文件）
2. 提取主题内容
3. 分类整理知识点
4. 生成主题笔记
```

### 流程3：对比分析笔记

```
1. 搜索相关概念
2. 提取对比信息
3. 创建对比表格
4. 生成对比分析
```

## 笔记质量检查清单

### 准确性检查
- [ ] 所有内容基于教材原文
- [ ] 数据、时间、人物信息准确
- [ ] 无编造或臆测内容

### 完整性检查
- [ ] 覆盖所有重要知识点
- [ ] 不遗漏关键概念和方法
- [ ] 包含相关背景和上下文

### 结构性检查
- [ ] 按照逻辑顺序组织
- [ ] 使用清晰的分类和层次
- [ ] 提供表格、列表等便于阅读的格式

### 考试导向检查
- [ ] 突出考试重点
- [ ] 标注易考点和难点
- [ ] 提供记忆技巧和关联

## 使用示例

### 示例1：生成第1章笔记

**用户请求**：请为第1章"绪论"生成学习笔记。

**执行流程**：
1. 读取教材第845-1488行（第1章内容）
2. 识别知识点类型：
   - 关键时间节点：1968年NATO会议、2000年IEEE标准等
   - 重要概念：软件架构、模块化开发、组件化技术等
   - 核心理论：SAAM、ATAM等架构分析方法
3. 按照模板生成笔记
4. 保存到`学习记录/章节笔记/第1章-绪论.md`

### 示例2：提取特定主题笔记

**用户请求**：请提取"模块化设计原则"相关内容。

**执行流程**：
1. 搜索教材中"模块化设计原则"相关内容
2. 提取六大原则及解释
3. 生成主题笔记
4. 保存到指定位置

### 示例3：生成对比分析笔记

**用户请求**：请对比分析"组件化"与"模块化"的区别。

**执行流程**：
1. 搜索"组件化"和"模块化"相关内容
2. 提取两者定义、特点、区别
3. 生成对比分析表格
4. 保存到学习记录

## 与其他技能的协作

- **exam-note-generator**：专注于生成结构化学习笔记

## 注意事项

1. **准确性优先**：所有内容必须基于教材原文，不得编造
2. **精确标注出处**：每个知识点应标明章节和行号（如可能）
3. **考试导向**：突出考试重点和常见考点
4. **结构化呈现**：使用表格、列表、分类等便于阅读的格式
5. **持续更新**：随着学习进度，及时更新和补充笔记内容
