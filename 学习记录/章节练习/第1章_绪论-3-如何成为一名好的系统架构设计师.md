# 第1章 绪论 - 如何成为一名好的系统架构设计师

## 单选题（共3题）

### 第1题

**题目：** 作为一名优秀的系统架构设计师，除了技术能力外，还需要具备的关键角色特质是（）。

**选项：**
- A. 仅需要具备开发能力
- B. 仅需要具备技术专家能力
- C. 既要是沟通专家也要是领导者
- D. 仅需要具备系统集成能力

**正确答案：** C

**你的答案：** C

**解析：** A：错误，开发能力只是其中一个方面；B：错误，技术专家能力不足以涵盖所有需求；C：正确，沟通能力和领导能力是架构设计师的关键特质；D：错误，系统集成能力只是其中一个方面。【教材依据】6种角色特质：包括沟通专家、领导者、战略技术专家、开发者、企业家和系统综合者。

---

### 第2题

**题目：** 在系统架构设计师的成长过程中，从工程师开始依次经历的正确顺序是（）。

**选项：**
- A. 工程师→技术专家→高级工程师→初级架构设计师→中级架构设计师→高级架构设计师
- B. 工程师→高级工程师→技术专家→初级架构设计师→中级架构设计师→高级架构设计师
- C. 工程师→初级架构设计师→高级工程师→技术专家→中级架构设计师→高级架构设计师
- D. 工程师→高级工程师→初级架构设计师→技术专家→中级架构设计师→高级架构设计师

**正确答案：** B

**你的答案：** B

**解析：** A：错误，高级工程师应在技术专家之前；B：正确，完全符合教材描述的演化过程；C：错误，初级架构设计师应在技术专家之后；D：错误，技术专家应在初级架构设计师之前。【教材依据】成长过程：描述了从工程师到高级工程师、技术专家、初级架构设计师、中级架构设计师、高级架构设计师的演化过程。

### 第3题

**题目：** 下列不属于架构设计师6种角色特质的是（）。

**选项：**
- A. 沟通专家
- B. 项目经理
- C. 企业家
- D. 系统综合者

**正确答案：** B

**你的答案：** C

**解析：** A：错误，沟通专家是架构设计师的角色特质之一；B：正确，项目经理不属于架构设计师的6种角色特质；C：错误，企业家是架构设计师的角色特质之一；D：错误，系统综合者是架构设计师的角色特质之一。【教材依据】6种角色特质：包括沟通专家、领导者、战略技术专家、开发者、企业家和系统综合者。
