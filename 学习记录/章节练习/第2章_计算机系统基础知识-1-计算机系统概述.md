# 第2章 计算机系统基础知识 - 计算机系统概述

## 单选题（共2题）

### 第1题

**题目：** 计算机系统的基本功能不包括（）。

**选项：**
- A. 接收和存储信息
- B. 自动进行数据处理和计算
- C. 输出结果信息
- D. 自主产生原始数据

**正确答案：** D

**你的答案：** D

**解析：** A：错误，这是计算机系统的基本功能之一-B：错误，这是计算机系统的基本功能之一-C：错误，这是计算机系统的基本功能之一-D：正确，计算机系统不能自主产生原始数据，需要按人的的要求接收信息【教材依据】它是按人的的要求接收和存储信息，自动进行数据处理和计算，并输出结果信息的机器系统。

### 第2题

**题目：** 计算机系统的基本构成要素包括（）。

**选项：**
- A. 仅包括硬件和软件
- B. 仅包括硬件和网络
- C. 硬件、软件及网络
- D. 仅包括处理器和存储器

**正确答案：** C

**你的答案：** C

**解析：** A：错误，缺少网络这一要素-B：错误，缺少软件这一要素-C：正确，完整包含了计算机系统的三个基本要素-D：错误，这只是硬件的部分组成【教材依据】计算机系统是指用于数据管理的硬件、软件及网络的集合。
