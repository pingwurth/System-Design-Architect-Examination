# 第1章 绪论 - 系统架构设计师概述

## 单选题（共6题）

### 第1题

**题目：** 下列哪项不属于架构设计师知识能力结构的10个方面（）。

**选项：**
- A. 战略规划能力
- B. 业务流程建模能力
- C. 项目投资回报分析能力
- D. 信息安全技术支持与管理保障能力

**正确答案：** C

**你的答案：** A

**解析：** A：错误，战略规划能力是必备的能力之一；B：错误，业务流程建模能力是必备的能力之一；C：正确，项目投资回报分析能力不在10个方面之内；D：错误，信息安全技术支持与管理保障能力是必备的能力之一。【教材依据】知识能力结构10个方面：包括战略规划能力、业务流程建模能力、信息数据架构能力等。

---

### 第2题

**题目：** 关于架构设计师应具备的专业知识，下列说法错误的是（）。

**选项：**
- A. 需要掌握业务领域知识和技术知识
- B. 只需要具备技术能力，不需要沟通能力
- C. 需要具备设计技能和编程技能
- D. 需要具备决策能力和谈判能力

**正确答案：** B

**你的答案：** B

**解析：** A：正确，这是架构设计师必备的专业知识；B：错误，沟通能力是架构设计师必备的专业素质之一；C：正确，这是架构设计师必备的专业技能；D：正确，这是架构设计师必备的管理能力。【教材依据】专业知识：包括掌握业务领域的知识、技术知识、设计技能、编程技能、沟通能力、决策能力、组织策略和谈判专家。

---

### 第3题

**题目：** 从技术角度看，架构设计师的三大任务不包括（）。

**选项：**
- A. 抽象设计
- B. 非功能设计
- C. 关键技术设计
- D. 项目成本设计

**正确答案：** D

**你的答案：** D

**解析：** A：错误，抽象设计是架构设计师的主要任务之一；B：错误，非功能设计是架构设计师的主要任务之一；C：错误，关键技术设计是架构设计师的主要任务之一；D：正确，项目成本设计不属于架构设计师的三大技术任务。【教材依据】从技术角度看，架构设计师的职责就是抽象设计、非功能设计和关键技术设计等三大任务。

### 第4题

**题目：** 根据组织划分方法，下列哪个不属于架构师的5大类（）。

**选项：**
- A. 业务架构师
- B. 主题领域架构师
- C. 解决方案架构师
- D. 项目架构师

**正确答案：** C

**你的答案：** D

**解析：** A：正确，属于组织划分的5大类之一；B：正确，属于组织划分的5大类之一；C：错误，解决方案架构师属于微软公司的分类方法；D：正确，属于组织划分的5大类之一。【教材依据】从组织上划分，架构师通常可分为以下5大类：业务架构师、主题领域架构师、技术架构师、项目架构师、系统架构师。

### 第5题

**题目：** 关于系统架构设计师的组织形式，下列说法正确的是（）。

**选项：**
- A. 只能是单个人的形式
- B. 必须是大型团队的形式
- C. 可以是个人、小组或团队的形式
- D. 只能采用小组的形式

**正确答案：** C

**你的答案：** C

**解析：** A：错误，架构设计师不限于单个人；B：错误，不一定要求大型团队；C：正确，符合教材描述，可以是一个人、一个小组或一个团队；D：错误，不限于小组形式。【教材依据】系统架构设计师是一个人或一个小组，也可以是一个团队。

---

### 第6题

**题目：** 根据微软公司的架构师分类方法，下列属于其4大类架构师的是（）。

**选项：**
- A. 主题领域架构师（Domain Architect）
- B. 企业架构师（Enterprise Architect）
- C. 业务架构师（Business Architect）
- D. 系统架构师（System Architecture）

**正确答案：** B

**你的答案：** D

**解析：** A：错误，属于组织划分的分类方法；B：正确，企业架构师（EA）是微软分类方法中的一类；C：错误，属于组织划分的分类方法；D：错误，属于组织划分的分类方法。【教材依据】参考微软公司对架构设计师的4大类：企业架构师EA、基础结构架构师IA、特定技术架构师TSA、解决方案架构师SA。
