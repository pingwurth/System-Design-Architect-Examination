### 第2题

**在uml图中，（请作答此空）展现了一组类、接口、协作和它们之间的关系。（）强调消息跨越不同对象或参与者的实际时间，而仅仅只是关心消息的相对顺序。（）软件和硬件组件之间的物理关系以及处理节点的组件分布情况。（）描述由模型本身分解而成的组织单元，以及它们之间的依赖关系。**

| 选项 | 内容 |
|------|------|
| ✅ **A** | **类图** |
| B | 对象图 |
| C | 部署图 |
| D | 定时图 |

**正确答案：A** | 你的答案：A ✓

**解析：**
- **类图**：展现了一组类、接口、协作和它们之间的关系
- **定时图**：强调消息跨越不同对象或参与者的实际时间，而不仅仅只是关心消息的相对顺序
- **部署图**：描述软件和硬件组件之间的物理关系以及处理节点的组件分布情况
- **包图**：描述由模型本身分解而成的组织单元，以及它们之间的依赖关系

### 第3题

**快速应用开发(Rapid Application development, RAD)通过使用基于（请作答此空）的开发方法获得快速开发。当（）时，最适合于采用RAD方法。**

| 选项 | 内容 |
|------|------|
| A | 用例 |
| B | 数据结构 |
| C | 剧情 |
| ✅ **D** | **构件** |

**正确答案：D** | 你的答案：D ✓

**解析：**
RAD是一种比传统生存周期法快得多的开发方法，它强调极短的开发周期。RAD模型是瀑布模型的一个高速变种，通过使用**基于构件的开发方法**获得快速开发。

**RAD的局限性：**
1. 并非所有应用都适合RAD。RAD对模块化要求比较高，如果有哪一项功能不能被模块化，那么RAD所需要的构建就会有问题
2. 开发者和客户必须在很短的时间完成一系列的需求分析，任何一方配合不当，都会导致RAD项目失败
3. RAD只能用于管理信息系统的开发，不适合技术风险很高的情况

### 第4题

**C语言程序经编译后生成的文件类型是（）。**

| 选项 | 内容 |
|------|------|
| A | 汇编代码 |
| ✅ **B** | **机器码** |
| C | 字节码 |
| D | 源代码 |

**正确答案：B** | 你的答案：B ✓

**解析：**
编译器将C语言等高级语言转换为**机器码**（如.exe文件），可以直接在计算机硬件上执行。而**字节码**是Java语言编译生成的中间代码，可以跨平台解释执行。

### 第7题

**在 UML 提供的系统视图中，（1）把构件部署到一组物理节点上，表示软件到硬件的映射和分布结构。（2）对组成基于系统的物理代码的文件和构件进行建模。**

**问题1：描述"把构件部署到一组物理节点上，表示软件到硬件的映射和分布结构"的是？**

| 选项 | 内容 |
|------|------|
| A | 进程视图 |
| B | 实现视图 |
| ✅ **C** | **部署视图** |
| D | 用例视图 |

**正确答案：C** | 你的答案：C ✓

**解析：**
UML对系统架构的定义包括5个系统视图：

| 视图 | 说明 |
|------|------|
| 逻辑视图 | 也称"设计视图"，表示类、子系统、包和用例实现的子集 |
| 进程视图 | 将可执行线程和进程作为活动类的建模，描述并发与同步结构 |
| **实现视图** | 对组成基于系统的物理代码的文件和构件进行建模 |
| **部署视图** | 把构件部署到一组物理节点上，表示软件到硬件的映射和分布结构 |
| 用例视图 | 最基本的需求分析模型 |

### 第8题

**面向对象动态分析模型描述系统的动态行为，显示对象在系统运行期间不同时刻的动态交互。其中，UML 2.0的交互模型包括（1）等，其他动态模型还有（2）等。**

**问题1：UML 2.0的交互模型包括哪些？**

| 选项 | 内容 |
|------|------|
| ✅ **A** | **顺序图和定时图** |
| ❌ B | 顺序图和状态图 |
| C | 协作图和活动图 |
| D | 状态图和活动图 |

**正确答案：A** | 你的答案：B ✗

**解析：**
本题考查UML 2.0的图。**交互图**包括：
- 交互概览图
- 定时图
- 顺序图（序列图）
- 通信图（协作图）

除此以外，**动态模型**还包括状态图和活动图等。

| 图类型 | 分类 |
|--------|------|
| 顺序图 | 交互图 |
| 定时图 | 交互图 |
| 通信图/协作图 | 交互图 |
| 交互概览图 | 交互图 |
| 状态图 | 其他动态模型 |
| 活动图 | 其他动态模型 |

**问题2：UML 2.0的其他动态模型包括哪些？**

| 选项 | 内容 |
|------|------|
| A | 用例图和类图 |
| ❌ B | 活动图和部署图 |
| C | 对象图和复合结构图 |
| ✅ **D** | **状态图和交互概览图** |

**正确答案：D** | 你的答案：B ✗

**解析：**
动态模型包括：**状态图**和**活动图**，以及交互图（含交互概览图）。注意交互概览图属于交互图，也属于动态模型。
