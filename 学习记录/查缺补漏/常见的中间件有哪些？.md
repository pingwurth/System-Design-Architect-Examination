按**功能分类**整理主流数据中间件，附作用、代表产品、适用场景，方便记忆和区分。

# 一、消息队列（异步通信、解耦、削峰）

核心：收发消息，实现服务异步解耦、流量削峰、事件驱动。

1. **RocketMQ**：阿里开源，高可用、事务消息友好，国内互联网、金融广泛使用
2. **Kafka**：高吞吐、大数据场景首选，适合日志采集、流计算、海量事件
3. **RabbitMQ**：协议完善、路由策略丰富，可靠性强，偏传统业务、外企
4. **ActiveMQ**：老牌开源 MQ，功能全，现在逐步被替代
5. **Pulsar**：多租户、分层存储，云原生场景热门，兼顾吞吐与可靠性

# 二、缓存中间件（热点数据加速、减轻库压力）

核心：内存存热点数据，降低数据库访问、提升响应速度。

1. **Redis**：主流，支持多种数据结构、分布式锁、消息、持久化，用途极广
2. **Memcached**：纯内存缓存，简单高性能，只支持简单 KV，功能单一

# 三、数据库中间件（分库分表、读写分离、数据库代理）

核心：接管数据库请求，实现分片、读写分离、路由、故障转移。

1. **Sharding-JDBC**：客户端分片，无独立服务，轻量，Java 生态主流
2. **MyCat**：服务端代理，跨语言，支持分库分表、读写分离、集群
3. **ProxySQL**：MySQL 专用代理，侧重读写分离、负载均衡、规则路由
4. **Atlas**：美团开源 MySQL 代理，轻量读写分离

# 四、数据同步 / ETL 中间件（数据流转、同步、集成）

核心：跨库、跨系统、跨集群数据迁移、实时 / 离线同步。

1. **Canal**：阿里开源，基于 MySQL binlog，**实时数据同步**（最常用）
2. **DataX**：阿里离线 ETL，全量数据迁移，支持几十种数据源
3. **Flink CDC**：实时增量同步，大数据生态主流
4. **Debezium**：开源 CDC 组件，对接主流数据库 + 消息队列

# 五、大数据计算 / 流处理中间件（实时计算、批处理）

核心：海量数据实时 / 离线分析、流式计算。

1. **Apache Flink**：实时计算标杆，流批一体，实时报表、风控、大屏
2. **Apache Spark**：主打离线批处理，也支持准实时，大数据分析、数仓计算
3. **Storm**：早期实时计算框架，目前使用减少

# 六、搜索引擎中间件（全文检索、多维查询）

核心：替代数据库做模糊检索、海量数据快速查询。

1. **Elasticsearch(ES)**：主流全文检索，日志分析、商品搜索、日志平台
2. **Solr**：老牌搜索引擎，偏传统企业、静态检索场景

# 七、时序数据库中间件（监控、物联网、时序数据）

核心：专门存储时间序列数据（指标、设备点位、监控数据）

1. **InfluxDB**：经典时序库
2. **Prometheus**：云原生监控标配，配合 Grafana 做监控大盘
3. **TimescaleDB**：基于 PostgreSQL 的时序库

# 八、分布式事务 / 数据治理类

1. **Seata**：分布式事务中间件，微服务跨库事务主流方案
2. **Apache DolphinScheduler**：大数据任务调度中间件，调度 ETL、计算任务
