# 系统架构设计师备考笔记

> 软考高级 · 系统架构设计师（System Architect）考试备考知识库

## 项目简介

本仓库用于系统性地备考**全国计算机技术与软件专业技术资格（水平）考试**（简称"软考"）中的**系统架构设计师**科目。内容涵盖教材笔记、章节练习、每日刷题、查缺补漏以及复习总结，同时集成了基于 Claude Code 的 AI 答题助手，可自动定位教材知识点并给出解析。

## 考试概述

系统架构设计师是软考**高级资格**之一，考试包含三个科目：

| 科目 | 题型 | 满分 | 合格线 |
|------|------|------|--------|
| 综合知识 | 75 道单选题 | 75 分 | 45 分 |
| 案例分析 | 5 道大题（选做） | 75 分 | 45 分 |
| 论文 | 4 选 1 写作 | 75 分 | 45 分 |

三科均需达到合格线，且成绩**不保留**，需一次性全部通过。

## AI 答题助手

本项目集成了 Claude Code 自定义 Skill：**`architect-for-soft-exam-assistant`**。

### 功能

当提供软考题目（选择题、填空题、案例分析、论文题目等）时，助手会：

1. 自动扫描教材章节目录，定位相关知识点所在章节
2. 读取对应教材内容，基于教材原文给出准确答案
3. 提供详细解析，关联相关知识点帮助理解

### 使用方式

在 Claude Code 中输入 `/architect-for-soft-exam-assistant`，然后粘贴题目即可获得解答。也可以直接粘贴题目文本，助手会自动识别并触发。

### 示例

```
/architect-for-soft-exam-assistant
请作答：以下关于串行总线的说法中，正确的是（ ）。
A. 串行总线一般都是全双工总线，适宜于长距离传输
B. ...
```

## 辅助脚本

`qoder/scripts/` 目录下提供了若干 Markdown 文档处理脚本：

| 脚本 | 用途 |
|------|------|
| `split_chapters.sh` | 将完整教材 Markdown 按章节拆分为独立文件 |
| `fix_heading_space.sh` | 修复 Markdown 标题后的空格格式 |
| `center_captions.sh` | 居中图片标题 |
| `picture_not_use.sh` | 检测项目中未被引用的图片文件 |
